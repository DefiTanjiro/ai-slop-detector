# Changelog

## 2.0.0

The skill now fixes slop, not only flags it.

- **Modes:** Create, Audit and Fix, each with its own steps.
- **Triage:** heavy, light or none, so a good screen is never changed just to be different.
- **Direction first:** five lines (product, character, world, moment, signature), plus the
  generic test and the competitor test.
- **Fixed pass order** for visual work (spacing, color, icons, copy, type, layout, details,
  visuals, motion) and for writing (facts, argument, stock language, rhythm, voice).
- **Patterns 101-140:** third-wave palettes (cream and terracotta), editorial cosplay, mono
  label voice, fake numbering, stat-card stuffing, effect components, interface copy tells,
  code-level motion tells, the avoidance aesthetic, missing states.
- **Severity** (H, M, L) and detect notes on all 140 patterns. Numbers 1-100 unchanged.
- **New references:** direction, tokens, app-screens, components, motion, copy (with product
  docs for PMs), quality floor, critique.
- **`scripts/scan.mjs`:** dependency-free static scan for 45 code and copy tells, with fixture
  tests in `tests/`.
- **Conflict rules** where sources disagree: monospace, numbering, hairlines, glass, case,
  default fonts and icon sets.
- **Credits** for every source in `CREDITS.md`.

## 1.0.0

- 100 patterns across visual design, UI, copy and AI images, with fixes.
